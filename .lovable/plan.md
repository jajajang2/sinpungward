
목표: 출석부의 3장 달력 캐러셀에서 2월을 제외한 좌우 달력의 마지막 주가 잘리는 문제를 해결하고, 좌우 달력이 지금보다 더 많이 보이도록 레이아웃을 재조정합니다.

1. 카드/캐러셀 높이 재설계
- `src/pages/AttendancePage.tsx`의 캐러셀 바깥 래퍼 높이와 각 카드 높이를 다시 늘려, 6주 달력이 항상 한 화면 안에 들어오도록 조정합니다.
- 특히 좌우 카드가 `scale`로 축소되면서 실제 표시 가능한 높이가 더 줄어드는 점을 반영해, 현재보다 여유 있는 기준 높이로 재설정합니다.

2. 월 제목 영역 축소
- 카드 상단의 월 텍스트(`yyyy년 M월`) 영역에서 `margin-bottom`, `padding-top/bottom`, 글자 크기 밸런스를 조정해 제목이 차지하는 세로 공간을 줄입니다.
- 중앙 달력은 강조를 유지하되, 달력 본문을 더 확보하는 방향으로 최적화합니다.

3. 좌우 달력 전용 그리드 압축
- 2월(가운데 달력) 외 좌우 달력에만 적용되는 주간 간격을 더 좁힙니다.
- `head_row`, `row`, `cell`, `day` 관련 클래스에서:
  - 주간 row gap 축소
  - 셀 최소 높이 축소
  - 내부 상하 패딩 축소
  - 필요 시 날짜/출석 수직 gap 축소
- 핵심은 마지막 주 숫자가 “잘리지 않고 모두 보이게” 만드는 것입니다.

4. Calendar 내부 여백 정리
- `Calendar` 컴포넌트 기본 `p-3`가 현재 카드 내부 높이를 과도하게 소비하고 있어, 출석부 캐러셀에서는 더 작은 패딩이 적용되도록 `AttendancePage`에서 덮어쓰거나 필요한 경우 공통 컴포넌트 쪽을 안전하게 조정합니다.
- `table / month / tbody` 높이 분배도 함께 정리해 실제 날짜 영역이 끝까지 내려오도록 만듭니다.

5. overflow/클리핑 원인 제거
- 현재 카드의 `overflow-hidden` 및 내부 래퍼 높이 계산(`calc(...)`) 때문에 마지막 주가 잘리는 부분을 점검해, 필요한 범위만 숨기고 날짜 그리드는 잘리지 않게 수정합니다.
- 카드 모서리 디자인은 유지하면서도 실제 달력 숫자는 전부 보이도록 구조를 다듬습니다.

6. 좌우 달력 노출량 확대
- 좌우 카드의 `translate-x` 값을 바꿔 중앙 카드 뒤에 더 많이 드러나게 조정합니다.
- 동시에 `scale`과 `opacity`를 미세 조정해서:
  - 더 많이 노출되지만
  - 중앙 달력보다 덜 강조되고
  - 카드형 캐러셀 느낌은 유지되도록 맞춥니다.
- 현재보다 좌우가 더 바깥쪽으로 보이도록 좌/우 각각 별도로 튜닝합니다.

7. 반응형 마감
- 현재 사용 중인 뷰포트(약 994x676) 기준에서 먼저 맞춘 뒤, 모바일/중간 폭에서도 월 제목과 마지막 주가 다시 잘리지 않도록 breakpoint별 높이/간격을 정리합니다.
- 최종적으로는 “중앙 달력은 강조”, “좌우 달력은 더 많이 노출”, “세 달 모두 월 제목과 마지막 주가 안 잘림” 상태로 맞춥니다.

기술적으로 수정할 파일
- 주 수정: `src/pages/AttendancePage.tsx`
- 필요 시 보조 수정: `src/components/ui/calendar.tsx` (공통 패딩/높이 분배를 더 유연하게 만들 경우)

완료 기준
- 좌우 달력 마지막 주 날짜가 전부 보인다.
- 월 제목이 잘리지 않는다.
- 달력 하단이 카드에 의해 잘리지 않는다.
- 좌우 이전/다음 달 카드가 지금보다 더 많이 노출된다.
- 중앙 카드 중심의 겹침 캐러셀 구조는 유지된다.

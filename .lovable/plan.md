
목표: 출석부의 3개월 달력을 “가운데 월 중심 + 양옆 월은 겹쳐 보이는 책장/책 넘김 방식”으로 바꾸고, 가운데 월만 날짜 진입이 가능하도록 상호작용 규칙을 정리합니다.

1. 달력 상호작용 규칙을 월별로 분리합니다
- 가운데 달력:
  - 날짜 클릭 시 해당 날짜의 출석부 상세로 진입
  - 현재처럼 선택 상태와 출석 인원 표시 유지
- 왼쪽/오른쪽 달력:
  - 어느 셀을 클릭하든 날짜 진입 없이 그 달이 가운데로 이동
  - 웹에서는 클릭, 모바일에서는 터치/스와이프 모두 가운데 이동으로 동작
- 이렇게 해서 “옆 달력을 눌렀는데 바로 출석부로 들어가는 문제”를 막습니다.

2. 웹 화살표 UI를 제거하고, 좌우 달력 자체를 네비게이션으로 바꿉니다
- 현재 `ChevronLeft`, `ChevronRight` 버튼은 제거합니다.
- 좌우 달력 카드 전체를 “이전/다음 달로 포커스 이동” 트리거로 변경합니다.
- 접근성도 함께 보강합니다.
  - 좌우 달력에 버튼 역할/포커스 가능 상태 부여
  - 키보드 사용 시 Enter/Space로 가운데 이동 가능하도록 처리

3. 3개월 레이아웃을 “겹침형 책 페이지 구조”로 재설계합니다
- 현재의 단순 3열 grid를 겹쳐 보이는 스택형 레이아웃으로 변경합니다.
- 가운데 달력은 가장 위 레이어에 크게 배치하고,
- 좌우 달력은 같은 크기로 키우되 바깥쪽 일부만 보이게 하여 가운데 달력 뒤로 숨어 있는 것처럼 만듭니다.
- 시각 구조 예시:
```text
   [이전달 일부] [가운데 달력] [다음달 일부]
      \__________ 가운데 뒤로 겹침 __________/
```
- 웹과 모바일 모두 같은 개념을 유지하되, 모바일은 더 좁은 폭에서 보이는 가장자리 비율만 줄입니다.

4. 달력 이동 애니메이션을 “책 페이지 넘김” 느낌으로 바꿉니다
- `focusedMonth` 변경 시 이전/현재/다음 달이 단순 교체되지 않고,
  - 좌우 이동 방향에 따라 슬라이드 + 스케일 + 투명도 변화가 함께 일어나도록 구성합니다.
- 핵심 모션:
  - 가운데 달력이 옆으로 밀리며 뒤 레이어로 들어감
  - 옆 달력이 앞으로 나오며 가운데로 정렬
  - opacity와 translate, scale을 함께 써서 책장을 넘기는 듯한 깊이감 구현
- 프로젝트에 이미 있는 `slide`/`scale` 계열 애니메이션 유틸과 Tailwind transition 패턴을 우선 활용합니다.

5. 모바일 제스처 동작을 추가합니다
- 모바일에서는 좌우 보이는 달력을 탭해도 가운데 이동 가능하게 하고,
- 추가로 달력 영역 전체에서 좌/우 스와이프 시 이전/다음 달로 이동하도록 연결합니다.
- 과도한 제스처 충돌을 막기 위해:
  - 가운데 달력 안의 날짜 탭은 그대로 날짜 선택
  - 수평 스와이프만 월 이동
  - 세로 스크롤과 충돌하지 않도록 최소 이동 거리 기준을 둡니다

6. 가운데 달력만 실제 선택 가능한 상태로 렌더링합니다
- 현재는 세 달 모두 `Calendar`에 같은 `onSelect`를 연결하고 있어 좌우 달력도 날짜 진입이 가능합니다.
- 이를 월별로 분기합니다.
  - 가운데 달력: `onSelect={handleSelectDate}`
  - 좌우 달력: 날짜 선택 비활성 또는 셀 클릭 가로채기
- 좌우 달력은 클릭 이벤트를 카드 레벨에서 받아 `setFocusedMonth(monthDate)`만 실행하도록 구조를 정리합니다.

7. 달력 크기와 셀 비율을 전반적으로 확대합니다
- 가운데 달력은 현재보다 더 크게 키우고,
- 좌우 달력도 같은 기본 크기를 유지하되 보이는 면적만 잘라 보여주는 형태로 변경합니다.
- 함께 조정할 항목:
  - 달력 컨테이너 높이
  - `cell` 최소 높이
  - 날짜 숫자 크기
  - 출석 인원 수 폰트 크기
  - 월 제목 영역 높이
- 모바일은 사용자가 기존에 요청한 9:20 체감 비율을 유지하면서 중심 달력이 더 시원하게 보이도록 폭/높이 균형을 다시 맞춥니다.

8. 시각적 상태를 더 명확히 구분합니다
- 가운데 달력:
  - 선명도 100%
  - 가장 높은 z-index
  - 선택/hover/active 상태 정상 표시
- 좌우 달력:
  - 약간 흐린 opacity 유지
  - 가운데 뒤에 일부 숨김
  - 클릭/터치 가능하다는 것을 subtle hover/tap 반응으로 표시
- 기존의 일요일 빨간색, 토요일 파란색, 출석 인원 강조는 유지합니다.

9. 구현 대상 파일
- `src/pages/AttendancePage.tsx`
  - 3개월 달력 구조 변경
  - 가운데/좌우 달력 상호작용 분기
  - 화살표 제거
  - 모바일 터치/스와이프 처리
  - 책장 넘김 애니메이션 상태 추가
- 필요 시 보조 스타일 정리를 위해 공통 유틸 클래스 사용 여부 점검
- `src/components/ui/calendar.tsx`는 공통 컴포넌트라 직접 수정은 최소화하고, 가능하면 `AttendancePage.tsx`의 `classNames`, wrapper, event handling으로 해결합니다.

10. 완료 기준
- 웹:
  - 좌우 달력을 클릭하면 그 달이 가운데로 이동
  - 가운데 달력에서만 날짜 클릭 시 출석부 상세 진입
  - 화살표 UI 없음
  - 달력 이동 시 책 넘김처럼 자연스럽게 전환
- 모바일:
  - 좌우 보이는 달력 탭 또는 스와이프로 가운데 이동
  - 가운데 달력만 날짜 진입 가능
  - 달력이 더 크게 보이고, 양옆은 일부만 보여 겹쳐진 구조가 유지됨


목표: 출석부 화면을 모바일에서 “좁아 보이지 않고”, 핵심인 달력/회원리스트/체크박스가 먼저 잘 보이도록 재구성합니다.

1. 전체 레이아웃을 모바일 우선으로 다시 나눕니다
- 현재는 데스크톱 2열 구조를 모바일에서도 거의 그대로 축소해서 쓰는 부분이 있어 화면이 답답해 보입니다.
- 모바일에서는 세로 스택 구조로 변경합니다.
  - 상단: 날짜/뒤로가기/요약
  - 중단: 그룹 탭
  - 본문 1: 회원 리스트 + 체크박스
  - 본문 2: 방문자 입력/목록
- 데스크톱에서는 지금처럼 2열 구조를 유지합니다.

2. 모바일에서 회원 리스트를 최우선 영역으로 올립니다
- 사용 목적상 모바일에서 가장 중요한 것은 출석 체크이므로 회원 리스트가 먼저 보여야 합니다.
- 방문자 입력 카드는 회원 리스트 아래로 내리고, 기본 높이를 줄입니다.
- 회원 리스트 영역은 모바일에서 화면 높이 기준 충분한 비율을 차지하도록 조정합니다.
  - 예: 화면의 절반 이상을 리스트가 차지
- 리스트 헤더(이름 / 출석)는 상단 고정으로 유지해 스크롤 중에도 체크하기 쉽게 합니다.

3. 방문자 입력 영역을 “접히는 요약 카드” 형태로 축소합니다
- 모바일에서는 방문자 입력이 공간을 너무 많이 차지하므로 기본 상태를 compact 형태로 바꿉니다.
- 기본 표시:
  - “방문자 n명”
  - “방문자 추가” 버튼
- 버튼을 누르거나 펼치면 이름/연락처/메모 입력 폼이 나타나도록 합니다.
- 입력 필드 높이, 패딩, 텍스트 크기를 모바일 기준으로 더 촘촘하게 줄입니다.

4. 달력 화면도 모바일 전용 비율로 다시 조정합니다
- 현재 3개월 미리보기는 모바일에서 폭을 많이 잡아먹을 수 있으므로 중심 달력을 더 크게, 양옆 미리보기는 더 얇게 만듭니다.
- 모바일 비율은 사용자가 요청한 9:20 느낌에 맞춰 중앙 달력이 넓게 보이도록 조정합니다.
- 좌우 화살표 버튼도 모바일에서 달력을 가리지 않도록 크기/위치를 다시 맞춥니다.
- 요일/날짜/출석 인원 텍스트도 모바일 전용 크기로 재조정합니다.

5. 모바일 전용 간격과 타이포를 따로 최적화합니다
- 현재 데스크톱 기준 padding/gap/font-size가 모바일에서 과하게 보이는 부분을 줄입니다.
- 대상:
  - 페이지 바깥 여백
  - 카드 내부 패딩
  - 그룹 탭 버튼 높이
  - 검색창 높이
  - 회원 row 높이
  - 방문자 카드 간격
- 체크박스 터치 영역은 작아지지 않도록 유지합니다.

6. 스크롤 동작을 역할별로 분리합니다
- 모바일에서 “페이지 전체 스크롤”과 “회원 리스트 내부 스크롤”이 충돌하지 않게 정리합니다.
- 원칙:
  - 페이지는 자연스럽게 세로 스크롤
  - 회원 리스트는 필요한 경우 내부 스크롤
  - 상단 요약/그룹 탭은 바로 접근 가능
- 이렇게 하면 “회원리스트가 안 보이는 문제”와 “하단 영역 때문에 본문이 밀리는 문제”를 같이 줄일 수 있습니다.

7. 사이드바/레이아웃 폭이 모바일 화면을 잡아먹는지 함께 점검합니다
- 현재 레이아웃이 모바일에서도 왼쪽 사이드바 폭을 그대로 점유하면 실제 본문이 매우 좁아질 수 있습니다.
- 모바일에서는 사이드바를 접힌 상태 또는 오프캔버스 방식으로 바꾸는 방향을 적용합니다.
- 본문은 전체 폭을 최대한 사용하게 만들어 출석부가 좁아 보이지 않게 합니다.

8. 검증 기준을 명확히 두고 마무리합니다
- 모바일에서 확인할 항목:
  - 출석부 첫 진입 시 회원 리스트가 바로 보이는지
  - 체크박스가 스크롤 없이도 여러 명 보이는지
  - 방문자 입력이 화면을 과도하게 차지하지 않는지
  - 달력 3개월 구조가 너무 답답하지 않은지
  - 그룹 탭/검색/방문자 입력이 모두 손가락으로 누르기 편한지

기술적으로 수정될 가능성이 높은 파일
- `src/pages/AttendancePage.tsx`
  - 모바일/데스크톱 분기 레이아웃
  - 회원 리스트/방문자 카드 순서 재배치
  - 달력 섹션 비율 조정
- `src/components/Layout.tsx`
  - 모바일에서 본문 전체 폭 확보 필요 시 조정
- `src/components/AppSidebar.tsx`
  - 모바일에서 사이드바가 본문 폭을 잡아먹지 않도록 개선 필요 시 조정

예상 구현 방향
```text
모바일
[상단 요약]
[그룹 탭]
[회원 리스트(우선, 크게)]
[방문자 요약 카드 / 펼치기]
[방문자 상세 목록]

데스크톱
[회원 리스트] [방문자 카드]
```

사용자 체감 변화
- 모바일에서 더 이상 “화면이 좁아서 안 보이는” 느낌이 줄어듭니다.
- 출석 체크에 필요한 회원 리스트가 먼저 보입니다.
- 방문자 입력은 필요할 때만 펼쳐 쓰게 되어 공간이 절약됩니다.
- 전체적으로 홈 화면에 추가해도 앱처럼 더 자연스럽게 보이게 됩니다.

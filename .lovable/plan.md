# 가족정보 Tree UI 변경 계획

기존 표(table) 형태의 가족정보를 **카드 + 선 연결 가계도(Tree)** 형태로 변경합니다. 입력/편집은 그대로 유지하되, **보기 모드(View)** 가 기본이고 **편집 모드(Edit)** 토글 시 기존 입력 컨트롤이 카드 안에 나타나도록 합니다.

## 변경 범위
- `src/components/members/MemberDetailPanel.tsx` 의 `<TabsContent value="family">` 영역만 교체
- 신규 컴포넌트: `src/components/members/FamilyTree.tsx`
- 기존 저장/불러오기 로직, 양방향 동기화, 자동 정렬(나이순), 본인 중심 배치 로직은 **그대로 재사용**

## UI 구조

### 데스크탑 (md 이상) — 가계도 형태
```text
        [부]──[모]              ← 부모 가로 연결(배우자선)
          │
   ┌──────┼──────┐               ← 부모→자녀 세로선
 [형]   [본인]──[배우자]          ← 형제 / 본인-배우자(하이라이트)
                  │
              ┌───┼───┐
            [자1][자2][자3]      ← 자녀 (출생순)
```

레벨 구성:
1. **조부모** (있으면)
2. **부모 / 시부모·장인장모** — 배우자끼리 가로선
3. **형제자매 + 본인 + 배우자** — 본인은 강조, 형제는 좌측, 배우자는 우측
4. **자녀** — 본인-배우자 아래 세로선, 자녀는 출생순 가로 배치
5. **손자녀** (있으면)

선은 CSS border + 절대 위치 div 로 그립니다 (외부 라이브러리 없이).

### 모바일 (md 미만) — 세로 카드 스택
```text
[부] [모]            ← 같은 그룹은 한 줄에 2장
[형] [누나]
─────────────────
[본인] (강조)
[배우자]
─────────────────
[자1]
[자2]
```
그룹 헤더(부모 / 형제 / 본인&배우자 / 자녀)로 묶고 카드를 세로로 쌓습니다.

## 카드 디자인

각 카드(`FamilyMemberCard`):
- **상단**: 관계 뱃지 (예: "아버지")
- **본문**: 이름(굵게), 생년월일·나이, 현재 부름, 연락처
- **본인**: `border-2 border-primary bg-primary/5` 강조, "본인" 뱃지
- **연결된 회원**: 우측 상단 `ExternalLink` 아이콘 (회원카드로 이동)
- **우측 상단 액션**(편집 모드일 때만): `Edit` 아이콘 → 인라인 편집 펼침, `Trash` 아이콘 → 삭제
- **Hover**: shadow-md + 비고(notes)·이메일 등 추가 정보를 `HoverCard` 로 표시
- 크기: 데스크탑 `w-44`, 모바일 `w-full`

## 접기/펼치기

- 그룹 단위 토글: "형제 (3)", "자녀 (2)", "손자녀 (1)" 헤더 클릭 시 해당 그룹 카드 영역 접기/펼치기
- `Collapsible` (이미 프로젝트에 존재) 사용
- 기본값: 모두 펼침. 상태는 컴포넌트 로컬 `useState`

## 보기/편집 모드

탭 우측 상단에 토글 버튼:
- **보기 모드 (기본)**: 카드만 렌더, 깔끔한 가계도
- **편집 모드**: 카드 안에 기존 `FamilyNameCombobox`, `RelationshipSelect`, 비고 `Input`, 삭제 버튼 노출 + "추가" 버튼 표시

저장 로직은 기존 `handleSave` 그대로(편집 모드에서 변경된 `family` state 가 그대로 저장됨).

## 그룹 분류 로직

기존 `familyGroup()` / `familyRank()` 를 확장해 5단계 레벨로 매핑:

| 레벨 | 관계 키워드 |
|------|-------------|
| L1 조부모 | 할아버지, 할머니, 외할아버지, 외할머니 |
| L2 부모 | 아버지, 어머니, 시아버지, 시어머니, 장인, 장모 |
| L3 형제·본인·배우자 | 형, 누나, 오빠, 언니, 동생, 형제, 자매 / 본인 / 남편, 아내, 배우자 |
| L4 자녀 | 아들, 딸, 자녀, 며느리, 사위 |
| L5 손자녀 | 손자, 손녀 |

매칭되지 않는 관계는 L3(본인 옆) 으로 폴백.

## 기술 세부

- 외부 라이브러리 추가 없음 (react-flow 등 미사용 — 단순 가계도이므로 CSS로 충분)
- 데스크탑 트리: `flex flex-col items-center gap-8` 컨테이너 + 각 레벨은 `flex gap-4` + 자식들 위에 `::before` 가상요소 대신 절대 위치 connector div
- 구체적으로 한 레벨의 `<div className="relative">` 안에 카드들을 배치하고 부모-자식 연결선은 부모 카드 하단에서 자식 카드 상단으로 가는 단순 세로선 + 형제간 가로선
- 작은 viewport 에서는 `useIsMobile()` 훅으로 분기하여 스택 뷰 렌더
- 본인 카드는 `member` props 로부터 합성(저장 X)
- 카드 액션: `Edit` 클릭 시 해당 카드만 편집 모드로 전환(편집 모드 토글과 별개로 카드별 인라인 편집 가능)

## 작업 순서

1. `FamilyTree.tsx` 생성 — props: `member`, `churchInfo`, `family`, `setFamily`, `memberList`, `onNavigateToMember`
2. `FamilyMemberCard` 서브컴포넌트 — view/edit 두 모드
3. 데스크탑 트리 레이아웃 + connector 선 CSS
4. 모바일 스택 레이아웃 + 그룹 헤더
5. `Collapsible` 그룹 접기/펼치기
6. `MemberDetailPanel.tsx` 의 family 탭 영역을 `<FamilyTree ... />` 로 교체, 기존 table JSX 제거
7. 편집 모드 토글 + 추가 버튼 위치 조정

DB 스키마/저장 로직 변경 없음. 기존 자동 동기화 / 정렬 / 본인 중심 배치는 트리에서도 동일 유지.
